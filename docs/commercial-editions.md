# Editions

The GPL development core has no license network call, telemetry, updater or paid unlock. No commercial edition is shipped.

Intended Free/Core includes ledger/security, provenance, full/split checkout, funding/refunds, limits, reconciliation, HPOS/Blocks, basic API/reporting. Split tender is an open **core** gate. Basic security/integrity/accessibility can never be premium-only.

Pro campaigns/rewards/vouchers/gifts/automatic funding/fees, Business FX/webhooks/accounting/reports, Marketplace vendor commission/settlement/payout/escrow and Enterprise integrations must be separate add-ons with explicit schema/dependency/tests, not hidden unfinished financial flows.

Entitlement expiry may limit updates/new premium setup only. Existing money, history, refunds/releases, reconciliation and exports must continue. Updater/licensing still needs TLS, signed manifests/package integrity, compatibility/rollback gates and minimal activation metadata. None is implemented. Future telemetry must be opt-in and omit financial/customer data.
