# ADR 0002: Split tender requires a certified payment adapter

Accepted. Wallet money is tender, never a coupon or negative fee. Order gross, line totals, taxes and commissions remain intact. Full wallet gateway reserves and captures the gross amount. Split tender must use a provider adapter that accepts an explicit external-due amount and reports a verified settlement reference. The core will reject generic gateways for split payment until that adapter passes real checkout/refund tests.

Research: [WooCommerce payment integration](https://developer.woocommerce.com/docs/block-development/extensible-blocks/cart-and-checkout-blocks/checkout-payment-methods/payment-method-integration/), [Store API checkout](https://developer.woocommerce.com/docs/apis/store-api/resources-endpoints/checkout), [HPOS](https://developer.woocommerce.com/docs/features/orders/high-performance-order-storage/recipe-book/). Public APIs do not document a universal arbitrary multi-tender contract. Treating a filter on order total as universal support risks under/overcharging and refunds. This is a release blocker for the requested universal split checkout capability, not a reason to compromise tax semantics.
